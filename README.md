# Mein Prozentrechner
Der kostenlose Online-Prozentrechner – Prozentwert, Prozentsatz und Grundwert in Sekunden berechnen.

Live-Tool: https://mein-prozentrechner.de

Features: Prozentwert (W = G × p / 100), Prozentsatz (p % = W / G), Grundwert (G = W / p %); Alltagsbeispiele: Rabatt, Mehrwertsteuer (19 %), Gehaltserhöhung; kostenlos, ohne Anmeldung, mobil optimiert.

Try it: https://mein-prozentrechner.de
